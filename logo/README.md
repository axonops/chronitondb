# ChronitonDB logo

| File | Use |
|---|---|
| `chronitondb-lockup-light.svg` | Icon and name, for light backgrounds |
| `chronitondb-lockup-dark.svg` | Icon and name, for dark backgrounds |
| `chronitondb-icon-light.svg`, `chronitondb-icon-light-512.png` | Icon only, for light backgrounds |
| `chronitondb-icon-dark.svg`, `chronitondb-icon-dark-512.png` | Icon only, for dark backgrounds |
| `chronitondb-social-preview.png` | GitHub social preview, 1280 by 640, set in the repository settings |

## Font and colours

The wordmark uses Schibsted Grotesk Bold, which is free under the SIL Open Font License and available on Google Fonts. In the lockup SVGs the letters are converted to shapes, so the font does not need to be installed. The icon has no text.

| Colour | Hex |
|---|---|
| Charcoal | `#26282C` |
| Off-white | `#EDEDED` |
| Orange accent | `#D8572A` |
